# POO_401_IA_1

Repositorio de la materia de Programacion Orientada a Objetos (POO), con ejercicios enfocados en topicos de Inteligencia Artificial (IA).

## Descripcion

Este proyecto organiza practicas y ejemplos para reforzar fundamentos de POO aplicados a casos de IA, como:

- encapsulamiento
- herencia
- polimorfismo
- capas y datasets
- metricas y pipelines
- ejercicios por unidad

## Estructura del proyecto

Estructura principal del repositorio:

```text
POO_401_IA_1/
|- pom.xml
`- src/main/java/
   |- Hola.java
   |- capas/
   |- dataset/
   |- unidad_1/
   |- unidad1/
   `- unidad2/
```

Algunas carpetas incluyen practicas por tema (por ejemplo, `herencia`, `polimorfismo`, `metrica`, `pipeline`, `dataset`, `vehiculo`, etc.).

## Requisitos

- Java 17
- Maven 3.8+ (recomendado)
- IDE Java (IntelliJ IDEA recomendado)

## Ejecucion basica

Compilar el proyecto:

```bash
mvn clean compile
```

Ejecutar pruebas (si aplica):

```bash
mvn test
```

Empaquetar el proyecto:

```bash
mvn clean package
```

## Objetivos de aprendizaje

- Aplicar principios de POO en codigo Java.
- Modelar problemas introductorios de IA con buenas practicas.
- Comprender organizacion por capas, procesamiento y metricas.
- Practicar diseno y lectura de proyectos modulares.
